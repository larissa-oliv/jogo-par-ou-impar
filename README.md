# Jogo Par ou Ímpar em Python

## Descrição
Este é um simples jogo de Par ou Ímpar desenvolvido em Python, onde o jogador compete contra o computador. O objetivo é adivinhar se a soma dos números escolhidos pelo jogador e pelo computador será par ou ímpar. O jogo permite múltiplas rodadas e acompanha o desempenho do jogador através de um placar.

## Funcionalidades
- Escolha entre Par ou Ímpar.
- Defina o intervalo de números (ex: 1 a 10).
- Jogue múltiplas rodadas.
- Acompanhe suas vitórias e derrotas.

## Como jogar
1. Clone o repositório para o seu computador:
    ```bash
    git clone https://github.com/larissa-oliv/jogo-par-ou-impar.git
    ```
2. Navegue até o diretório do projeto:
    ```bash
    cd jogo-par-ou-impar
    ```
3. Execute o jogo:
    ```bash
    python parOuImpar.py
    ```

## Exemplo de Uso
1. Escolha Par ou Ímpar (P/I).
2. Defina o intervalo máximo de números.
3. Escolha um número dentro do intervalo.
4. O computador escolherá um número aleatório.
5. A soma dos números será calculada e verificada se é Par ou Ímpar.
6. O vencedor da rodada será anunciado e o placar atualizado.
7. Você pode jogar novamente ou sair do jogo.
